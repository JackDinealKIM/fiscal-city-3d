# 재정도시 : 나라살림 5년

2026년 대국민 재정교육 아이디어 공모전(기획예산처) 출품작 — **공모분야 ④ 재정을 배우는 새로운 방법(게임·교구 등 학습 도구)**
제안자 · 김재동 (개인)

- 실행: **`index.html` 더블클릭** (설치·로그인·인터넷 연결 없음)
- 기술: Three.js r147 벤더링 + 바닐라 JS 단일 페이지 (빌드 도구 없음)
- 데이터: 2026년 대한민국 확정예산 (기획예산처 「2026년 예산 국회 확정」 2025.12.2. / 국회예산정책처 나보포커스 제130호)

## 무엇을 하는 게임인가

플레이어는 인구 100만 **재정도시의 시장**이 되어 5년(2026~2030) 동안 해마다 예산을 짭니다.

1. **예산 편성** — 복지·돌봄, 교육, 안전·재난, 성장·R&D, 교통·SOC, 환경, 문화·관광 7개 분야를 0.1조 단위로 배분하고,
   지방세율(60~140%)·국고보조(0~2.5조)로 세입을 설계합니다.
2. **결산** — 세출이 세입보다 크면 **국채**가 자동으로 발행되고, 다음 해에는 **이자(4.2%)** 가 먼저 빠져나갑니다.
   시민 행복도·경제 성장·안전·신뢰·재정건전성 5개 지표가 다시 계산되고 연도 등급(S~D)이 매겨집니다.
3. **돌발 재정 수요** — 집중호우, 감염병, 청년 고용, AI 전환, 노후 교량, 학교 통폐합 6종.
   **예비비 / 추경(국채) / 민간 협력** 중 하나를 고르고, 그 선택의 재정 결과를 봅니다.
4. **재정 개념 퀴즈** — 회계연도 원칙, 추경, 예비비, 국채 이자, 조세부담률, 2026년 예산 규모 등 8문항과 해설.
5. **5년 결과** — 평균 등급과 함께 **내 배분 vs 2026년 정부 배분**을 막대그래프로 비교합니다.

## 3D 도시가 곧 피드백

- 분야별 지구(district)의 **건물 높이**가 그 분야 배분에 따라 자라고 줄어듭니다. 증액하면 **공사 크레인과 먼지**가 뜹니다.
- 시민 49명이 지구를 걸어 다니고, 차량 12대가 순환도로를 달립니다. 행복도가 낮으면 도시에 **시위**가 열리고,
  좋은 결산에는 **불꽃과 색종이**가 터집니다.
- 국채가 쌓이면 도시 조명이 차가워지고, 하늘의 노을도 함께 흐려집니다.
- 지구를 클릭하면 카메라가 그 분야로 이동하고 해당 슬라이더가 강조됩니다.

## 조작

| 동작 | 방법 |
|---|---|
| 도시 회전 | 마우스 드래그 / 한 손가락 드래그 |
| 확대·축소 | 휠 / 두 손가락 핀치 |
| 예산 조정 | 슬라이더 (0.1조 단위) |
| 다음 해 | `결산하고 다음 해로` |
| 모바일 | 우측 상단 `예산 편성` → 하단 시트 |

```
├── city3d.js       Three.js 도시 렌더러 (지구·건물·시민·차량·연출·카메라)
├── game.js         게임 규칙·지표 계산·UI·모달 흐름
└── three.min.js    Three.js r147 (외부 CDN 없이 오프라인 실행)
```
